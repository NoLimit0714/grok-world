# Adapters (future)

This app is intentionally separate from Jarvis.

When you want to link later, add an adapter here — for example:

- `jarvis.ts` — map Jarvis hub WebSocket topics into Grok World events
- optional “promote” actions from the sim into Jarvis tools

Until then, leave this folder empty of runtime code. The bridge only uses the local Grok + world sim path.
